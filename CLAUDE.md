# Claude Code Configuration for KnowNote

## Skills

### ego-browser
The ego-browser skill provides AI agents with a browser automation capability using the ego-lite browser. Agents can interact with websites, fill forms, take screenshots, and automate browser operations.

**Usage:**
```
/ego-browser describe what you want to do
```

**Features:**
- Navigate websites and interact with pages
- Fill forms and submit data
- Take screenshots and extract page data
- Test web applications
- Reuse user sessions without conflicts

For more details, see `.agents/skills/ego-browser/SKILL.md`
